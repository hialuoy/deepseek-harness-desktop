常见问题 / FAQ

首次启动为什么会安装东西?

应用需要 dsh 运行时。首次启动会自动下载私有 Node.js 与 dsh 到 ~/.dsh/toolchain/(需联网,通常 1-2 分钟),之后秒开、离线可用。安装超过 30 秒会显示"请耐心等待",属正常现象。

数据存放在哪里?

配置与数据在 ~/.dsh/ 目录,日志在 ~/.dsh/desktop.log。卸载时删除该目录即可完全清理。

如何卸载?

macOS:把应用拖入废纸篓;Windows:控制面板卸载。可选清理 ~/.dsh/ 目录。

Where is my data stored?

Config and data live in ~/.dsh/; logs in ~/.dsh/desktop.log. Delete that directory to fully uninstall.
